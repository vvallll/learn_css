# ✦ Learning CSS

A collection of hands-on CSS exercises and notes, built while learning how to style and lay out web pages. ⋆｡°✩

### ⊹ What I learned

* ✦ Working with selectors, combinators, classes, IDs, and pseudo-classes
* ✦ Understanding the cascade, inheritance, specificity, and how CSS rules are applied
* ✦ Working with colors, backgrounds, borders, shadows, gradients, and opacity
* ✦ Styling text with different fonts, sizes, weights, spacing, alignment, and decoration
* ✦ Understanding the CSS box model, including `margin`, `padding`, `border`, and `width`/`height`
* ✦ Working with different units such as `px`, `%`, `em`, `rem`, `vh`, and `vw`
* ✦ Positioning elements with `static`, `relative`, `absolute`, `fixed`, and `sticky`
* ✦ Building layouts with Flexbox and understanding its main properties
* ✦ Creating responsive layouts and adapting elements to different screen sizes
* ✦ Using pseudo-elements, transitions, transforms, and other CSS features to add visual details
* ✦ Practicing CSS through small exercises, experimenting with different approaches, and debugging unexpected results

### ♡ One topic at a time

Unlike my HTML project, this repository isn't one finished website. It's a collection of small exercises from different lessons, each focused on a new CSS concept.

`learning → experimenting → "why is this here?" → fixing it → understanding it → trying again` ⊹
